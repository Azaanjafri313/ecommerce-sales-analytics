\# E-Commerce Sales Analytics Dashboard



An end-to-end data analytics project analyzing Brazilian E-Commerce sales data using SQL, PostgreSQL, and Power BI.



\---



\## Project Overview



This project demonstrates a complete data analytics workflow:



\- Data preparation

\- Database design

\- SQL transformations

\- Data modeling

\- Business intelligence dashboard development



The objective is to analyze sales performance, customer behavior, product performance, payments, sellers, and logistics.
